# Visual asset inventory

## Quiet Horizons wallpaper

- Project asset: `app/src/main/res/drawable-nodpi/cinematic_horizon.webp`.
- Created 30 October 2026 with the built-in image generation tool for this project. No reference photographs, third-party logos, paid image service or downloaded stock artwork were used. Generated artwork is not evidence of exclusive copyright; review distribution requirements before public release.
- Generated source was converted to an opaque WebP at quality 88 for Android packaging. Stored dimensions: 1672 × 941, approximately 135 KiB. At ARGB8888 its decoded pixel storage is about 6 MiB. `drawable-nodpi` avoids density-driven upscaling; decoding runs on IO and the image is cropped to the screen. Minimalist theme does not decode it.
- The original PNG remains in the development machine's Codex generated-images folder. The app consumes the self-contained WebP in the repository.

Generation prompt (built-in tool, no CLI/API key):

Composition for TV launcher: upper right distant landscape is the focal point, left third is darker calm negative space for navigation, bottom third dark and uncluttered for application tiles. Full bleed wallpaper only, no interface, no text, no logos, no watermark. High quality 1920x1080 or equivalent 16:9.
